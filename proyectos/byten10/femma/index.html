Proyecto:
Femma Studio
Cliente:
Ten10 Design

Proyecto realizado para Ten10 Design.
Femma Studio es un estudio de pilates que convive con una cafetería de especialidad saludable, concebido como un espacio de bienestar integral para mujeres. La propuesta busca equilibrar movimiento, nutrición y comunidad, ofreciendo un entorno donde ejercitar el cuerpo, relajarse y disfrutar de una pausa consciente. El espacio está diseñado para transmitir calma, comodidad y cercanía, invitando a vivir el bienestar como un ritual cotidiano.
